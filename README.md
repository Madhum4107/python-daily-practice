# Python Fundamentals — Daily Practice

A small learning repository documenting my early Python practice: variables, data types, operators, conditionals, and short exercises.

> This repository is a learning log—not a showcase project. The examples are intentionally small as I build programming fundamentals.

## Topics covered

| Topic | Files / examples |
|---|---|
| Variables & data types | `variable.py`, `datatype.py` |
| Operators | `operator.py` |
| Conditional logic | `if else*.py`, `ifelse.py` |
| Practice questions | `question.*.py` |

## Run an example

Requires Python 3.

```bash
python datatype.py
```

Use the same command with any individual exercise file. Filenames are kept as they were during practice.

## Planned organization

As the practice grows, examples will be grouped into topic folders and rewritten with clearer filenames, short comments, and sample outputs.
